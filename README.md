# ころころ ことば

ひらがなサイコロを 50音表のルールで転がして、お題のことばをスタンプしていく Three.js パズルゲーム。

## あそびかた

```bash
python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開く（ES Modules を使うので `file://` では動かない）。

- → / ← で転がすと行が変わる（あ→か→さ…）、↓ / ↑ で転がすと段が変わる（あ→い→う…）。端は反対側へ回り込み、空欄（や行・わ行など）は飛ばす
- 番号つきマスに同じ文字を上にして止まるとスタンプ。全部そろえばクリア
- 押した文字マスは、サイコロが離れると「印」のブロックになって通れない
- 手数制限は最短手数ぴったり
- 氷（すべる間は文字が変わらない）、回転床（サイコロが 90° 回り行と段の向きが入れかわる）、ひび床（離れると崩れて穴になる）、文字の門、濁点床・半濁点床
- Z: もどす / R: さいしょから / H: ヒント（次の一手） / M: 音 / Esc: ステージ選択。スマホはスワイプで操作

## 開発

- `logic.js` 盤面ロジックとソルバー（描画に依存しない）
- `levels.js` ステージ定義
- `scene.js` Three.js の描画と演出、`sound.js` WebAudio の効果音、`main.js` 進行と UI
- `node tools/check.mjs` で全ステージを幅優先探索で解き、最短手数（par）を検証する
- `node tools/analyze.mjs <番号>` で最短解の本数、各仕掛けを外したときの手数、最初の一手ごとの手数（罠の有無）を見る
- `node tools/batch.mjs '<json>'` で盤面に対して単語と文字マスの配置を総当たりし、仕掛けが効いている候補を探す
- `node tools/trace.mjs <番号>` で最短解を1手ずつ表示する
- 各ステージの狙い（気づきポイント）は `levels.js` の `aha` に書いてある
